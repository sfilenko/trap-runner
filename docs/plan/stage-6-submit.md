### Task 6.3: PR у форку capstone

- [ ] **Step 1 [ЛЮДИНА]: гілка і тека**
```bash
cd <твій клон 2026-agentic-engineering-crash-course-capstone-HW>
git checkout -b serhii-filenko
mkdir -p submissions/serhii-filenko
```
  `submissions/serhii-filenko/README.md`: назва, одне речення про гру, посилання на репо `trap-runner`, на відео, на `docs/evidence.md`. Файли курсу в корені (`README.md`, `RUBRIC.md`, `.github/`) не чіпай.

- [ ] **Step 2: PR**
```bash
git add submissions/serhii-filenko
git commit -m "Capstone: Trap Runner"
git push -u origin serhii-filenko
gh pr create --web
```
  Заповни шаблон: **справжнє ім'я** (піде в сертифікат) · проєкт · відео · практики з доказами (з `docs/evidence.md`) · інструменти та MCP · **що вирішував я, а що агент** · перевірка (вивід `pnpm check` і `pnpm e2e` або посилання на CI). Куди відкривати PR (у свій форк чи в курсовий репо) — звір з інструкцією курсу.

- [ ] **Step 3: незалежна перевірка перед здачею.** У репо бази знань (`D:\AITools\AgenticEngineering`) запусти агента `homework-reviewer` на `D:\AITools\trap-runner` з рубрикою capstone. Він ставить PASS / NOT-EARNED / FAIL на кожен критерій. Виправ NOT-EARNED до здачі.
