# Intent: Trap Runner (capstone)

## Навіщо
Особистий платформер; capstone курсу, де кожну практику видно в репо.

## Що вважаємо готовим (вимірювано)
1. Гра проходиться від level-01 до останнього рівня в браузері.
2. `pnpm check` exit 0, `pnpm e2e` exit 0, CI зелений.
3. Відео 1–2 хв і PR у форку capstone.

## Чого НЕ робимо
Звук, спрайти, power-up'и, кілька типів ворогів, збереження, мобільне керування.

## Бюджет проєкту (записано ДО apply)
- час: ≤ 25 год (план 19.5)
- $ / токени: ліміт підписки Claude, окремої $-стелі немає (рішення людини, 2026-10-02)
- як міряємо: `/cost` (або /usage) наприкінці кожної сесії; `total_cost_usd` у логах циклу

## Зміна A: add-core-gameplay — бюджет (записано ДО apply)
- час: ≤ 180 хв · output: ліміт підписки Claude, окремої стелі в токенах немає · $: окремої $-стелі немає (як у бюджеті проєкту, рішення людини, 2026-10-02)
- як міряємо: `/usage` (% ліміту підписки) до і після сесії apply; час — за годинником

### Зміна A — факт (2026-10-02)
- час: **53 хв** з 180 — за часом комітів: propose 14 хв (`1e0072d` 01:17:54 → `c4485f7` 01:31:37), apply 31 хв (→ `72dc0b4` 02:02:14, 7 зупинок на коміти людини), archive і Purpose 8 хв (→ `e6465e8` 02:10:44)
- витрати: `/usage` → вкладка Session **лише сесії оркестрації й рев'ю** (Task 2.0–2.5, не apply): $8.95 (оцінка за цінами API; на підписці окремо не списується), claude-opus-5-5 66.0k output, 107.4k input, 28.8m cache read, 180.0k cache write; wall 1h 3m 56s, API 13m 28s, 87 запитів
- не виміряно: витрати сесій propose і apply (знімаються лише в самій сесії до `/exit`); % ліміту підписки до apply не записано
- висновок: у межах бюджету часу; для зміни B знімати `/usage` у кожній сесії перед `/exit`
